# Прямий вузол

Базовий з'єднувальний вузол для мотузок однакового діаметра і допоміжних задач.

## Коли використовувати

- Для тимчасового з'єднання без динамічних навантажень
- У побуті, пакуванні, фіксації тканин

## Обмеження

- Не рекомендований як основний вузол безпеки в альпінізмі чи рятуванні
