# Альпійський метелик

Петельний вузол, який в'яжеться в середині мотузки. Добре працює при навантаженні в різних напрямках.

## Коли використовувати

- Для створення проміжної точки кріплення
- Для ізоляції пошкодженої ділянки мотузки

## Переваги

- Універсальний напрямок навантаження
- Підходить для технічних і рятувальних робіт

## Обмеження

- Потребує тренування для швидкого в'язання в рукавицях
