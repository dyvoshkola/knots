# Простий вузол

Найпростіший стопорний вузол. Дуже швидко в'яжеться, але під великим навантаженням може сильно затягуватися.

## Коли використовувати

- Як тимчасовий стопор на кінці мотузки
- Для фіксації в побутових сценаріях без критичних навантажень

## Переваги

- Максимально простий
- В'яжеться інтуїтивно

## Обмеження

- Важко розв'язується після серйозного навантаження
- Не найнадійніший для відповідальних робіт
